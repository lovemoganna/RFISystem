# RFI System (RFI 模板库)

这是一个用于 CEX（中心化交易所）风控系统的 Request for Information (RFI) 模板库。

## 项目简介

RFI 模板库旨在帮助风控团队高效地向用户收集所需信息、文档和证明材料，以满足合规性、反洗钱（AML）以及日常风险控制的需求。

## 主要内容

- **rfi-templates (1).html**: 包含当前版本 (v7) 的所有风控 RFI 模板的展示与管理界面。

## 技术栈

- HTML5 / CSS3 (包含深色模式支持)
- JavaScript

## 开发与部署

直接在浏览器中打开 `rfi-templates (1).html` 即可使用。
